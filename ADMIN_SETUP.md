# Admin Panel Setup & Authentication Guide

This project uses a secure, dual-layer authentication system for the Admin Panel. It leverages **Firebase Authentication** for identity and **Cloud Firestore** for role verification.

## 1. Authentication Architecture

The Admin Panel is fully separate from the Customer and Restaurant panels.

*   **Identity**: Uses standard Firebase Authentication (Email/Password).
*   **Role Verification**: On login, the system checks the `admins` collection in Firestore.
    *   **Rule**: A user can ONLY access the admin panel if their `uid` exists as a document in the `admins` collection.
    *   **Security**: Regular users (customers/restaurants) cannot access `/admin` even if they are logged in, because they lack the `admins` document.

## 2. Setting Up the First Admin

Since there is no public "Sign Up" page for Admins (for security reasons), the first admin must be created manually.

### Step-by-Step Guide

1.  **Create a User in Firebase Auth**:
    *   Go to your Firebase Console -> Authentication.
    *   Click "Add User".
    *   Enter email (e.g., `admin@akrhunger.com`) and password.
    *   Copy the **User UID** generated by Firebase.

2.  **Create the Admin Document in Firestore**:
    *   Go to Firebase Console -> Firestore Database.
    *   Start a new collection named `admins` (if it doesn't exist).
    *   **Document ID**: Paste the **User UID** you copied earlier (CRITICAL: Do not use an auto-generated ID).
    *   **Fields**:
        *   `name` (string): "Super Admin"
        *   `email` (string): "admin@akrhunger.com"
        *   `role` (string): "super_admin"
        *   `createdAt` (timestamp): Current time

### Example Firestore Structure
```text
collection: admins
  document: <FIREBASE_AUTH_UID>
    fields:
      name: "Admin Name"
      email: "admin@example.com"
      role: "super_admin"
```

## 3. Accessing the Panel

1.  Navigate to `http://localhost:3000/admin/login` (or your deployed URL).
2.  Log in with the email/password you created.
3.  The system will verify your UID against the `admins` collection.
4.  Upon success, you will be redirected to the Dashboard.

## 4. Admin Features

*   **Dashboard**: Overview of total orders, revenue, and active restaurants.
*   **Menu Approvals**: View pending menu items from restaurants. Approve them to make them live on the customer app.
*   **Restaurants**: Manage registered restaurants (Enable/Disable/Delete).
*   **Orders**: View all platform orders (if implemented in `admin/orders`).

## 5. Troubleshooting

*   **"Loading..." Stuck**: This usually means the user is logged in via Firebase Auth but does **not** have a corresponding document in the `admins` collection. The system is retrying the check.
    *   *Fix*: Ensure the Firestore Document ID matches the Auth User UID exactly.
    *   *Fix*: Check browser console for permission errors.
*   **White Screen on Login**: Ensure you are on the latest version of `app/admin/layout.tsx` which allows unauthenticated access to the login route.
